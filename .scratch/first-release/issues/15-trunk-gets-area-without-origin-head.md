# The trunk branch gets a per-branch area when `origin/HEAD` isn't set

Category: bug
Status: needs-triage

## Problem

The README says "The trunk branch gets no area." Without a `trunk` line, `trunk_branch` relies only on `refs/remotes/origin/HEAD`. That is unset after `git remote add`, in clones made by some tools, and in repos with no remote. The trunk is then empty, so `main` gets `branches/main/`.

## Notes

Add fallbacks after `origin/HEAD`: `init.defaultBranch`, then whichever of `main` or `master` exists locally. An alternative is to have `init` write a `trunk` line when it can detect the trunk, and warn when it can't.
