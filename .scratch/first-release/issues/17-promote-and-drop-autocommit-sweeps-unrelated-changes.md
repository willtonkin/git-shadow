# `promote` and `drop` commit everything in the shadow repo

Category: bug
Status: needs-triage

## Problem

`promote`, `promote --into` and `drop` each call `commit_shadow`, which runs `git add -A` on the whole shadow repo. Any unrelated pending edits (for example, a spec being edited in another worktree) get committed under "chore: promote per-branch files from …". The README describes committing only as `autocommit` at session end, and doesn't say these commands commit at all.

## Notes

Stage only the paths the command touched (`git add -A -- branches/<slug> <promoted targets>`), and document that these commands commit. This is a close relative of 06.
