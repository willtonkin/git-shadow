# No way to snooze a gone branch

Category: enhancement
Status: needs-info

## Problem

A per-branch area counts as "gone" as soon as its local branch is deleted. `hook-start` then reports it in every session until it's promoted or dropped. Deleting a local branch while its PR is still open is common, and in that case the right answer is "not yet", but there's no command for it.

## Notes

A `shadow keep <branch> [--until <date>]` could record the snooze in the area's `.branch` file, and `gone_branches` would skip snoozed areas.

## Comments

**2026-10-01:** Most of this is covered by `.scratch/merge-detection/spec.md`: a gone branch whose PR is still open will no longer be reported. What's left: snoozing when `gh` isn't available, or when the branch has no PR. Revisit once merge detection lands.
