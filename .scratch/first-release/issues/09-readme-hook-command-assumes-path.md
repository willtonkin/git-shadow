# The README's hook snippet assumes `shadow` is on the hook's PATH

Category: bug
Status: needs-triage

## Problem

The README's Claude Code snippet uses a bare `shadow hook-start`. Hooks may run with a different PATH from the user's interactive shell (`~/.local/bin` isn't guaranteed to be on it), and then the hook fails without any error. The note "use an absolute path if…" is easy to miss.

## Notes

Lead with the absolute path in the snippet. Better still, add a `shadow install-hooks` that writes the entries with the resolved path. Writing to another tool's settings file should ask for confirmation first.
