# Promote's numbering and link rewriting are shallow

Category: enhancement
Status: needs-triage

## Problem

`shadow promote` with `numbered`:

- only numbers files directly inside the numbered path, not files in subfolders;
- only rewrites references **between the promoted files**. A link to an unnumbered proposal from anywhere else, such as another branch's area or a `.scratch` spec, breaks silently.

## Notes

The second point is the one that matters. Either rewrite references across the whole shadow repo, or list the references it didn't rewrite so they can be fixed by hand.
