# Switching branch mid-session leaves the per-branch instructions out of date

Category: enhancement
Status: needs-triage

## Problem

`hook-start` tells the agent which per-branch area to write into, but only once, at session start. If the checkout switches branch partway through (Conductor workspaces do this), the instructions name the old branch, and `.branch-shadow` still points at the old area until the next `sync`. New files then land in the wrong branch's area.

## Notes

The agent's tools write through `.branch-shadow`, so re-syncing the link is enough to fix where files land. A `PreToolUse` hook on write tools could run a cheap `sync`, or `.branch-shadow` could be resolved when it's used instead of when the session starts. The instructions printed at session start would still name the old branch, so they should stop naming it.
