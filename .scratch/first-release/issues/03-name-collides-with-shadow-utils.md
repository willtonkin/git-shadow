# The name `shadow` collides with existing tools

Category: enhancement
Status: needs-triage

## Problem

`shadow` is the name of the Linux shadow-utils package (`/etc/shadow`, `passwd`, `useradd`). It's hard to search for and likely to clash in package managers (Homebrew, apt, AUR).

## Notes

A `git-` prefix such as `git-shadow` would avoid the clash, and git would pick it up as `git shadow`. Renaming affects the binary, `SHADOW_HOME`, the `.shadow` manifest name, `.branch-shadow`, the exclude-block markers, and the README. Existing users would need a migration for the manifest name and exclude markers, so this is cheapest to do before the first release.

This is a naming decision for the maintainer.
